# Finish 2 — Phase 2 Implementation Plan (vocabulary & routing)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The P2 slice of the Finish 2 design: composite rework (D8), transform operator (D9), multi-source (D7), recipes (D5), and the first four effect ports (gradient map, posterize, halftone, riso). Collage becomes real: `source → transform → composite`.

**Architecture:** Composite and transform are SHADER work (the transform is a pure frag effect — an inverse-uv sample with transparent outside, so it needs ZERO engine changes; deviation from D9's "rides the D2 machinery" note, recorded as a ruling). The one engine-semantic change: unwired effect inputs bind TRANSPARENT black (alpha 0) instead of opaque black in BOTH engines, which is what makes composite's unwired-B passthrough automatic. Multi-source activates the dormant `sourcePath` field. Recipes add migration v7 (append-only to `MIGRATIONS`).

**Tech Stack:** unchanged.

**Spec:** [docs/superpowers/specs/2026-09-08-finish-2-design.md](../specs/2026-09-08-finish-2-design.md) (D5, D7, D8, D9 + effect roster)

- Engines: the unwired-input fallback texture becomes `[0,0,0,0]`; missing SOURCE images keep opaque black (separate texture) so an unset artwork still reads as a black page.
- The v1 mix contract "amount=0 → passthrough A" (T12's engine test depends on it) STILL holds.

- Create: `shaders/transform/transform.frag`, `shaders/transform/effect.json`
- Create: `test/parity/cases/transform.json` + golden

**Interfaces:**
- Params: `x`, `y` (float −1..1, default 0 — page-fraction offset), `scale` (0.05–8, default 1), `rotate` (−180..180 deg, default 0), `pixel` (bool, default false — nearest sampling emulated in-shader via floor(uv·uRes)/uRes).
- Frag: inverse-transform the uv (translate, rotate, scale around center), sample uTex0; outside [0,1]² → `vec4(0)` (transparent — composite-over positions layers).

- Parity case: `source → transform(x 0.15, y −0.1, scale 0.6, rotate 20) → output 512x731`.

## Self-review notes

- Transform-as-frag is the load-bearing simplification: no engine work, parity by construction. If in-shader nearest emulation (pixel mode) proves ugly, drop the param rather than adding engine sampling modes.
- The transparent-unwired change (T1) is GLOBAL to all effects: any shader relying on opaque-black unwired inputs changes behavior. Audit: only mix reads uTex1 unwired today; vhs/dither/jpeg always have uTex0 wired in practice. Goldens re-verify everything anyway.
- Recipes deliberately do NOT auto-wire into the chain — wrong guesses are worse than one manual wire.
- Halftone cmyk mode is a SCREEN preview of separation, not actual channel export — don't oversell it in the README.
- Second parity source (source2.png) must be generated by the golden writer like source.png (committed, deterministic).
- Migration v7 is append-only; sqlx checksums forbid touching v1–v6 strings.
